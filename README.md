# スキ値札

BOOTH を見ているあいだ、今月の予算の残りを右下に出し続ける Chrome 拡張。
カートに入れるとき・カートを開いたとき・注文を確定する前に「あと ¥8,500。買うと残り ¥7,000 だよ」と囁く。

## 入れ方

1. Chrome で `chrome://extensions` を開き、右上の「デベロッパーモード」を ON
2. 「パッケージ化されていない拡張機能を読み込む」で `src/` を選ぶ
3. ツールバーのスキ値札から、毎月の予算と月の始まりの日 (給料日など) を決める

## できること

| 場所 | 動き |
|---|---|
| BOOTH のどのページでも | 右下に「今月の残り」。3 割を切ると黄色、こえると赤 |
| 商品ページ | 種類ごとに「買うと残りいくら」。「カートに入れる」を押すと一度止めて囁く (入れるか、やめておくか) |
| カート (`ショップ.booth.pm/cart`) | 開いたときに、カートの合計と買ったあとの残りを囁く |
| ご注文内容確認 (`checkout.booth.pm/checkout/step3`) | 開いたときに囁く。「注文を確定する」を押すと自動で記録する (確定ボタンは止めない。同じ注文は二重に数えない) |
| ツールバー | 予算、月の始まり、囁くかどうか、今月の記録 (消す・手で足す)、月ごとの合計 |

- データは `chrome.storage.local` にだけ置く。BOOTH のページは読むだけで、どこにも送らない
- ページの作りはクラス名ではなく「お支払金額」「小計:」「このショップのレジに進む」などの文字で探す (クラス名は変わりやすいので)

## テスト

```sh
npm test        # 予算の計算 (Node)
npm run e2e     # 拡張を入れた Chrome (headless) で確かめる
```

`e2e` は公開されている商品ページを 1 つ開く。カートとご注文内容確認は `test/fixtures/` の写し (個人の情報なし) に
Chrome の中で差し替えるので、本物のカートや注文には何も送らない。Chrome 137 以降は `--load-extension` が
効かないので、DevTools の `Extensions.loadUnpacked` で入れている。

## まだ

- 支払いに失敗した注文も、確定ボタンを押した時点で記録される (ツールバーから消せる)
- 「ギフトとして贈る」は止めない
- 購入履歴からの取り込み (記録が消えたときに作り直す)、設定の同期、バックアップ
